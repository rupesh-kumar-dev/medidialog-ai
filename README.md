# Health Sage AI

Build a Complete AI-Powered Healthcare Assistant Web Application — MediSage AI

Create a complete, modern, professional, responsive, AI-powered healthcare web application called “MediSage AI.”

MediSage AI is an intelligent healthcare assistant designed to help users understand their symptoms, have conversations with an AI health assistant, explore possible health conditions, assess potential health risks, learn about general health topics, and understand when professional medical attention may be appropriate.

The application must feel like a real-world, production-quality healthcare technology platform, not a simple chatbot or static website.

The website must be highly interactive, visually engaging, easy to understand, and contain many meaningful clickable elements.

Do not mention B.Tech, college, university, academic project, student project, practical submission, prototype, assignment, or educational project anywhere in the user-facing application.

The application must clearly state that MediSage AI is an AI-powered health information and decision-support assistant and does not provide definitive medical diagnoses or replace qualified healthcare professionals.

22. AI Safety

The AI must:

Never claim certainty about diagnosis.

Never say “You definitely have X.”

Use “possible,” “may be associated with,” or “could be consistent with.”

Ask follow-up questions when necessary.

Recommend professional medical consultation when appropriate.

Identify potential emergency warning signs.

Never prescribe prescription medicines.

Never advise stopping prescribed medication.

Avoid unsafe medication instructions.

Clearly communicate uncertainty.
